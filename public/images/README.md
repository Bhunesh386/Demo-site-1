# Image Asset Requirements

All UI imagery MUST use the defined placeholder images until high-fidelity assets are provided. 
Never hotlink images from external domains.

## Slots & Aspect Ratios
- `hero.avif`: 16:9 (Desktop) / 3:4 (Mobile fallback)
- `room-deluxe.avif`: 3:2
- `room-super-deluxe.avif`: 3:2
- `room-royal-suite.avif`: 3:2
- `heritage-compass.svg`: Scalable, vectorized
